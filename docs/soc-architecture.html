Provenance boundaries

The full-week CICIDS2017 benchmark and separately downloaded CIC-DDoS2019 extension retain distinct dataset identities. The 170,217-flow Thursday capture remains a legacy historical view and is never a fallback for the expanded index.

Actual service health

API health probes show reachability at request time. A healthy TCP/HTTP check does not prove stream ingestion, Kafka lag, Spark throughput, or data freshness. Unreachable services are shown unavailable, not simulated.

Architecture limits

Full-flow exploration currently uses the verified local SQLite index, not a full-benchmark Elasticsearch index. Per-flow model predictions, grounded AI explanations, reviewed ATT&CK mappings, and Sigma execution are not represented as implemented.

Architecture reflects the local project implementation. Runtime service state is volatile; use the SOC health endpoint for current checks. Full data is kept local and excluded from Git.
